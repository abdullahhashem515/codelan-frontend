# صور «من الميدان»

ضع هنا صوراً **حقيقية** من أعمال نفّذتموها: خزائن شبكات، تمديدات، كاميرات مركّبة، غرف خوادم، بدالات.
لا صور مخزون — القسم وُجد ليكون دليلاً.

- الصيغ: `webp` (الأفضل) أو `jpg` / `png` / `avif`
- العرض: حتى **1600px**، والحجم: أقل من **300KB** لكل صورة
- العدد المقترح: من 6 إلى 12

## اسم الملف = الترتيب والتعليق

```
01__غرفة الخوادم__Server room.webp      ← عربي + إنجليزي
02__تركيب كاميرات مراقبة.jpg             ← نفس التعليق للغتين
03.jpg                                   ← بلا تعليق
```

الرقم في البداية يحدد الترتيب فقط ولا يظهر.

## الظهور

بعد إضافة الصور: `npm run build`. القسم يظهر تلقائياً بعد «المنهجية».
ما دام المجلد بلا صور، القسم غير موجود في الصفحة أصلاً.
